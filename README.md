# Portfoli · Joan

Web portfolio en formato feed: proyectos de audiovisual, editorial y branding, filtrables por etiqueta (`?filter=audiovisual`, `?filter=editorial`, `?filter=branding`, `?filter=sobre-mi`, `?filter=contacto`).

- `index.html`: toda la web. Los proyectos están en la lista `ITEMS`, dentro del `<script>`.
- `assets/`: fotos (`.webp`, con miniatura `-t.webp`) y vídeos (`.mp4`, con póster `-poster.jpg`).
