# Portfoli · Joan

Web portfolio minimalista: carrusel vertical a pantalla completa con una cabecera flotante en forma de isla que abre la lista de proyectos.

- `index.html`: toda la web. Los proyectos están en la lista `PROJECTS`, dentro del `<script>`.
- `assets/`: fotos (`.webp`, con miniatura `-t.webp`) y vídeos (`.mp4`, con póster `-poster.jpg`).
