# Portfoli · Joan

Web portfolio minimalista: fondo gris claro, rueda 3D de proyectos (gira sola y acelera con la rueda del ratón o arrastrando), visor por proyecto y cabecera en rectángulo redondeado que filtra por audiovisual, editorial y branding (`?filter=`).

- `index.html`: toda la web. Los proyectos están en la lista `PROJECTS`, dentro del `<script>`.
- `assets/`: fotos (`.webp`, con miniatura `-t.webp`) y vídeos (`.mp4`, con póster `-poster.jpg`).
