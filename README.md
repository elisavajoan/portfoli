# Portfoli · Joan

Web portfolio minimalista: fondo gris claro, carrusel vertical estrecho y centrado, y una cabecera en rectángulo redondeado que filtra por audiovisual, editorial y branding (`?filter=`).

- `index.html`: toda la web. Los proyectos están en la lista `PROJECTS`, dentro del `<script>`.
- `assets/`: fotos (`.webp`, con miniatura `-t.webp`) y vídeos (`.mp4`, con póster `-poster.jpg`).
